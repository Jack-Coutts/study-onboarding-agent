1What goes in

🧪A public study

Raw results from Metabolomics Workbench, downloaded once and fingerprinted so every result traces back to the exact files.

📝A task file

The human choices: which column is the outcome, which groups to keep, which samples are quality controls.

📐The table rules

The exact layout the analysis pipeline needs. This is what the AI is judged against.

Then reads what passed and what didn't.

dSays "done"
